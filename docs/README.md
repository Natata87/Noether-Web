# Documentação do Noether Web

Esta pasta concentra documentação diretamente ligada ao desenvolvimento do jogo web.

Estrutura sugerida:

```text
docs/
├─ architecture/   # decisões técnicas, backend, multiplayer
├─ systems/        # combate, frequência, itens, progressão
├─ ui-ux/          # design system, wireframes e decisões visuais
└─ testing/        # planos de playtest e bugs conhecidos
```

Documentos gerais de universo, roteiro e Bíblia de Noether podem viver em um repositório/documentação separada no futuro, evitando misturar lore extensa com o código do cliente web.
